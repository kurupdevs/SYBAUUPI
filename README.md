## ✨ What is FoodEat?

**FoodEat** is a modern food-ordering web app. Browse a curated menu of burgers, pizza, sushi, desserts and drinks, add dishes to your cart, and check out in seconds. Built with a bright, 3D doodle art aesthetic that makes ordering feel like a treat.

- 🧾 Curated menu with categories, search & filtering
- 🛒 Persistent cart (localStorage) with live totals, delivery, and tax
- 💳 Checkout flow with order confirmation & ETA
- 🎨 3D doodle design system (hard shadows, chunky borders, playful type)
- ⚡ SSR-ready — TanStack Start + Vite
- 📱 Fully responsive, mobile-first

---

## 🚀 Quick Start

```bash
# 1. Install
bun install

# 2. Run dev server
bun run dev

# 3. Build for production
bun run build
```

Open http://localhost:8080 and start ordering.

## 🗂 Project Structure

```
foodeat/
├── src/
│   ├── routes/               # File-based routing
│   │   ├── __root.tsx        # App shell, meta, fonts
│   │   ├── index.tsx         # Landing page
│   │   ├── menu.tsx          # Full menu + search + filter
│   │   ├── cart.tsx          # Cart with quantity controls
│   │   ├── checkout.tsx      # Checkout + order confirmation
│   │   └── about.tsx         # About page
│   ├── components/
│   │   ├── site-header.tsx   # Sticky nav with cart badge
│   │   ├── site-footer.tsx   # Footer with socials
│   │   └── menu-card.tsx     # Dish card
│   ├── lib/
│   │   ├── menu-data.ts      # Menu items + categories
│   │   └── cart-store.ts     # Reactive cart store (useSyncExternalStore)
│   └── styles.css            # Design tokens, 3D doodle utilities
├── docs/                     # README assets
└── package.json
```
